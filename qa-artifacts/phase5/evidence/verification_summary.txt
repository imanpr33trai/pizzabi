Live defects found and fixed during this QA
1. Checkout overlay leaked the Cart header through the status-bar inset on every
   checkout screenshot. Fix: overlay Surface fills the screen; statusBarsPadding()
   is applied to the inner content Box (PizzoraNavHost.kt).
2. At 320dp + 1.5x font scale, the quote-error Row let the message consume all
   width, collapsing Retry off-screen and inflating the banner. Fix: message
   Text uses Modifier.weight(1f) (CheckoutScreen.kt). New regression test
   `quoteErrorRetryKeeps48dpTargetOnScreenAt320dpAnd15xFont` asserts Retry stays
   inside the banner with a >=48dp target.
